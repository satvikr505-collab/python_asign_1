# Week 1 Assignment: Python Fundamentals for Data Analytics

This folder contains nine independent Python programs for the Week 1 tasks.

## Requirements
- Python 3.9 or newer
- No third-party packages are required

## How to run
Open this folder in VS Code. Open the terminal and run one file at a time:
`python task1_python_basics.py`

Replace the filename with the program you want to execute. For Task 8, the text file
`student_introduction.txt` is created in the current working directory when the
program runs. Task 9 keeps records in memory until you exit the program.
